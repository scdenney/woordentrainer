# Woordentrainer

Vocabulary practice and pronunciation for *Nederlands in gang* (A1): <https://scdenney.github.io/woordentrainer/>

Quiz yourself on each chapter's words in rounds of 10, and hear every word. The Werkwoorden tab has conjugation tables and drills; the Examen tab has a study guide and a mock test (oefentoets) built on Oefentoets 1. Your progress is saved in your own browser.

This repo is generated from a private course repo. Changes made here directly will be overwritten.
